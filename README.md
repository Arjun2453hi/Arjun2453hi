## 🧠 Transformer Layer Analysis — TARLP

A project exploring **task-adaptive Transformer compression** and layer importance.

The work investigates which BERT encoder layers contribute most to a particular task and how unnecessary layers can be removed while retaining model performance.

* Gradient-based layer importance
* Probe-based importance analysis
* Task-specific layer selection
* Transformer layer pruning
* Recovery fine-tuning
* Computational efficiency analysis

The approach achieved significant FLOPs reduction while maintaining competitive performance against compact Transformer architectures.

**Python · PyTorch · Transformers · BERT · Deep Learning**

[View Repository →](https://github.com/Arjun2453hi/TDL_proj)
